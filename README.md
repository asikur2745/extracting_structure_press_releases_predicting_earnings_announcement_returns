## 📝 Description

This application implements Wu et al.'s (2025) paper from ICAIF'25. It turns unstructured earnings press releases into clear market signals. The software uses:

- **oLDA Topic Modeling:** This helps identify key themes in the text.
- **Transformer Embeddings:** It employs advanced models like BERT, FinBERT, and MPNET for text analysis.
- **GPT-4o Interpretability:** This makes the results easy to understand.
- **Econometric Analysis:** The application rigorously analyzes the financial data.
